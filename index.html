Quel Jeu?

Une vue à 360°. Devine le jeu vidéo, puis retrouve l'endroit sur sa carte.

Le multijoueur n'est pas disponible ici : il faut ouvrir l'artefact sur claude.ai (connecté) ou le site déployé avec Docker.

Comment jouer

  1. Regarde autour de toi dans la vue : un panorama 360° ou une simple capture d'écran (glisse pour te déplacer, pince ou molette pour zoomer).
  2. Trouve le nom du jeu. Si ta réponse est incomplète (« Zelda », « GTA », « Red Dead Redemption » sans le 2…), on te demande de préciser : ce n'est pas compté comme une erreur.
  3. Une fois le jeu trouvé, sa carte s'ouvre : place ton repère là où la vue a été prise.
  4. Points : jusqu'à 1 000 pour le nom (−200 par erreur) et jusqu'à 4 000 pour la position.
